- **纯静态高可用**：无第三方外部图片依赖，纯 CSS/SVG 渐变与图标渲染，极速秒开。

- **SEO & GEO 优化**：全页面独立 Title、Meta Description、规范 Canonical、XML Sitemap、Robots 协议与 JSON-LD 结构化数据。

## 本地预览

启动内置静态服务器：
```bash

```
在浏览器中打开 `http://127.0.0.1:8080/` 即可访问。
